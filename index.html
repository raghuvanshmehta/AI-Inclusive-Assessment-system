Four Dedicated Learner Categories

Every student is unique. Choose your default accommodation profile with complete freedom to customize individual controls anytime.

👤

No Special Need

Standard Interface

Clean, modern interface with standard text sizing and spacing, while keeping all accessibility customization controls accessible.

  • Standard typography
  • Default spacing
  • Full customization access
👁️

Low Vision

High Contrast

Enhanced visual contrast, enlarged text sizes (scalable up to 22px), high-visibility focus borders, and built-in text-to-speech read-aloud support.

  • Large scalable text
  • High-contrast palette
  • Read-Aloud speech synthesis
  • Zoom-friendly layout
⚡

ADHD

Focus Mode

Distraction-reduced single-question presentation, reduced animations, optional gentle break reminders, and focused progress milestones.

  • One question at a time
  • Reduced animations
  • Gentle break reminders
  • Minimal visual clutter
📖

Dyslexia

Readable Typography

Dyslexia-friendly typography, increased line height (1.9x), relaxed letter spacing, left-aligned content, and clear answer separation.

  • Specialized font stack
  • Increased line & word spacing
  • Left-aligned text structure
  • Distinct answer panels
